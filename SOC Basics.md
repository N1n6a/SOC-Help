As a SOC Analyst, you should know how to document. It's one of the, if not most, needed skill in the field.
A good documentation can save loads of time for Tier 2 Analysts (In case it needs escalation). A bad one slows everyone down and can let a real attack go unnoticed.

New to SOC work? Read the sections in order, since each one builds on the one before... mostly XD
Already have some experience? Jump straight to the section you need.
